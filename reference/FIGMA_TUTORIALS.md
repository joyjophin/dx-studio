# Optional Figma tutorial kit

`kits/figkit.py` draws an illustrative Figma UI3-style window and common controls.
It is an optional educational helper, not an official Figma integration. The kit
may lag the real interface. Verify the current workflow in primary documentation
or the actual app before claiming a shortcut, menu item or feature works today.

Copy figkit.py beside scene.py and import it after the DX Studio drawing API.
Derive callouts from the kit's component geometry. Make the visible labels,
palette, cursor, action times and highlights editable. Separate key demo elements
into layers instead of treating the entire interface as one flattened layer.

Use generic product names and assets for general-purpose explainers. Figma remains
a third-party trademark; this project is not affiliated with or endorsed by Figma.
