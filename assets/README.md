# Bring your own assets

The original private sticker pack and GIFs are intentionally excluded. DX Studio
works without them. Every supplied template renders with vector shapes and bundled
fonts only. Add your own licensed PNG poses to a project's `assets/Avatars/`, or
use **+ Media** in DX Editor for images, GIFs and video.

See [asset guide](../docs/ASSETS.md) for replacement rules and licensing records.
