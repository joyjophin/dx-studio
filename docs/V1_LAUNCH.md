# v1.0 launch scope

The first full product launch is v1.0.0. Earlier 0.x releases remain available.
Project format stays at version 1; existing projects retain their explicit layouts.

- [x] Guided setup, launcher, dependency diagnostics and an editable first project.
- [x] Source-aware visual clip trim/split and persistent selection groups.
- [x] Reviewed folder relinking, complete portable bundles and compatibility guidance.
- [x] Bounded preview caching and a reproducible ten-minute project benchmark.
- [x] Export readiness, useful failure guidance, both aspect ratios and audio checks.
- [x] A quiet first-project guide, visible recovery and actionable empty/error states.
- [x] Accurate docs, matching editor/skill packages, checksums and release preparation.

Critical verification covers saved edits, undo/recovery, moving a portable project,
source timing after a split, cache invalidation, audio/video export and archive
contents. A benchmark is a measurement of one machine and fixture, not a general
real-time playback guarantee. Fresh-user usability and additional hardware remain
valuable follow-up work; do not represent simulated user journeys as user research.

Publish the GitHub v1.0.0 tag and attachments only after the reviewed commit passes CI.
