Create with your AI assistant

Your assistant creates the video in its own coding workspace. DX Editor opens the editable project so you can refine it and export. Follow these four steps at your own pace.

Give your assistant the kit

Use an assistant workspace that can run Python, inspect rendered images, and read/write a project folder you share. A text-only chat can help write a script, but cannot verify a finished video.

Download the skill ZIPRead the skill ↗
  1. Extract the ZIP and keep its resources together. If your assistant supports skills, add it using that assistant’s skill setup.
  2. Otherwise, share the extracted kit folder and ask your assistant to read SKILL.md and its linked resources.
  3. Choose a project folder your assistant can write to. The kit needs Python, Cairo and FFmpeg; ask the assistant to follow docs/INSTALL.md in its workspace.
How do I check whether my assistant can do this?

Ask: “Can you run Python, inspect rendered images, and read/write the project folder I share? Use the DX Studio kit and tell me if a dependency is missing.” Sharing this chat alone does not grant file access.

Start with a useful brief

Fill in what you know. This builds a prompt to copy into your assistant; DX Studio does not generate or send it for you.

Style, narration and source material

Attach those files in your assistant’s workspace. This walkthrough does not upload them.

Preview or edit your starter prompt

Copy this into your assistant after sharing the kit. You can edit the prompt directly; changing the brief fields rebuilds it.

Bring back the project, then make it yours

Wait for your assistant to finish and ask it for the full project folder path. You need the editable project as well as the video.

Editable folder — contains project.json, the scene source and assets. Saved edits may also appear in settings.json.

MP4 — watch and share the finished video.

Portable project ZIP — move the editable project between workspaces or computers.

  1. If you receive a ZIP, extract it first and follow its OPEN-ME.md for the matching engine.
  2. Choose Open my AI project below and paste the path to the folder containing project.json. In a portable bundle, that is the inner project/ folder.
  3. Change words in Text or Captions, select a layer to move/scale/hide it, and adjust timing on the timeline.
  4. Wait for All changes saved, then use Export → Build this export for the updated MP4.
I only received an MP4, or my project will not open

An MP4 cannot restore separate editable layers. Ask the assistant for the DX Studio project folder or portable project ZIP. Check that you selected the folder containing project.json, not the ZIP, MP4 or kit folder. If a project uses a different engine, follow its OPEN-ME.md.

Keep the same chat for the next revision

  1. In DX Editor, wait for All changes saved and choose Continue with AI.
  2. Describe the change and choose Prepare AI handoff. Copy its follow-up prompt into the same chat.
  3. With access to the same local project folder, your assistant can read your saved edits and update the source files.
  4. After the assistant finishes, return to DX Editor and choose Review file updates → Reload AI changes. Then review and export the revised video.
No shared folder access? Attach the JSON handoff and Download full project ZIP in your assistant’s workspace. Ask for an updated editable project and open the returned folder here. The same chat preserves creative context; it does not automatically sync files.

DX Studio does not connect to an AI provider or silently replace your edit. You choose what to share and when to load revised files.
